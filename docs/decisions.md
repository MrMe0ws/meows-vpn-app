# Журнал решений

Формат: дата — решение — почему. Новое — сверху.

- **2026-11-17 — Windows: установщик MSI через jpackage/WiX с обёрткой `light.exe -sval`** (встроенный WiX падает на ICE-валидации); обновление — тихий `msiexec` по тегу `windows-v*`. Автозапуск/протокол — в HKCU (без администратора). Флаги — плашка с кодом страны (нет эмодзи-флагов в Windows).
- **2026-11-17 — по умолчанию на Android «цвета из обоев»** (канон Material You), пока пользователь не выбрал палитру.
- **2026-11-17 — Windows: Compose Desktop + то же Go-ядро, режим системного прокси.** TUN на Windows требует администратора и Wintun — отложен. Ядро для Windows — тот же `core/` (общие routing/geo/conf; точки входа `android_main.go` под тегом `android` и `desktop_main.go` под `!android && !cgo`).
- **2026-11-17 — палитры «Серая» (Neutral) и «Монохром» (Monochrome)** добавлены для тех, кому яркое не по душе; режим темы по умолчанию — «Авто».
- **2026-11-17 — приложение называется «Meows»** (латиницей, без «VPN»); «Мяус VPN» — название сервиса. User-Agent подписки — `MeowsVPN/<версия>`.
- **2026-11-17 — маршрутизация: правила подписки главные.** Вшиты roscomvpn-файлы (как у Happ), гео следует за панелью (`GeoUpdater`); расширенное «все российские сайты» выключено по умолчанию; российские приложения мимо VPN — отдельный флаг, включён. Причина: шаблоны владельца используют теги roscomvpn (`whitelist`, `geoip:direct`), которых не было во вшитых файлах Breeze — часть правил молча отбрасывалась.
- **2026-11-17 — универсальная APK (1.1.0):** ядро собрано под все ABI; armeabi-v7a/x86/x86_64 — через cgo и NDK 29 (Go для них без cgo не линкуется). arm64 оставлен чистым Go.
- **2026-11-17 — нижняя панель прячется при прокрутке вниз** и возвращается при прокрутке вверх (`FloatingToolbarDefaults.exitAlwaysScrollBehavior`) — стандартное поведение M3 Expressive, освобождает место под список.
- **2026-11-17 — действия главной в нижней плавающей панели** (FloatingToolbar), а не шестерёнка/«+» вверху: по гайдлайнам M3 Expressive и эргономике — зона большого пальца. Подтверждено пользователем по макету.
- **2026-11-17 — лапка вместо кота в кнопке при подключении:** силуэт `paw.png` (из иконки), красится в `primary` выбранной темы; спящий кот остаётся для отключённого состояния.
- **2026-11-17 — настройки: свёрнутые разделы + страницы.** Список рос; по канонам M3 — прогрессивное раскрытие. Роутер `SettingsPage`.
- **2026-11-17 — всё главное на главной, без нижней навигации.** Пользователь не хочет ходить на «Серверы»; два места не оправдывают NavigationBar.
- **2026-11-17 — спящий кот при отключении** (`sleep_cat.webp`, фон вырезан), логотип при подключении; «Zzz» анимацией в Compose.
- **2026-11-17 — QR через zxing-android-embedded**, а не ML Kit/Google code scanner: работает без Google Play Services.
- **2026-11-17 — автообновление через GitHub Releases** (APK вне Play). Установка через FileProvider + системный установщик.
- **2026-11-17 — `.dat` без сжатия в APK** (`noCompress`): иначе `openFd` падает («file can not be opened as a file descriptor»).
- **2026-11-17 — сборка из зеркала `C:\MeowsBuild\src`:** Gradle не принимает кириллицу в пути проекта.
- **material3 1.5.0-alpha04:** в 1.4.0 stable Expressive API скрыты (internal), 1.5.0-rc требует AGP 9.1 и compileSdk 37 — не готовы мигрировать.
- **Ядро arm64:** оставлен исходный `libxkcore.so` из Breeze; пересборка из Xray-core `a52db8f6ed19` + `core/` даёт тот же размер. Остальные ABI требуют cgo → NDK.
- **FGS type `specialUse` (subtype `vpn`)** для VpnService на targetSdk 34+.
- **Основа — Breeze VPN:** логику подписок/ядра оставили (рабочая), UI переписали на Compose + Material 3 Expressive.
