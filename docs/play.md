# Google Play

Приложение выпускается в двух вариантах (Gradle flavor, `Edition.isPlay` в коде):

| | `direct` (GitHub/сайт) | `play` (Google Play) |
|---|---|---|
| Артефакт | APK, `.\build.ps1` | AAB, `.\build.ps1 -Play` → `android\dist\MeowsVPN-play.aab` |
| Автообновление с GitHub, `REQUEST_INSTALL_PACKAGES`, FileProvider | есть | **нет** (политика Play запрещает самообновление) |
| «Кабинет», «Продлить», ссылки на оплату, «Открыть кабинет» при лимите устройств | есть | **нет** (политика платежей Play); в уведомлениях тоже нет ссылок на оплату |
| Текст `announce` с панели (в нём бот и кабинет) | показывается | **скрыт** |
| «Поддержка» (бот) | есть | есть (открывает бота — возможный вопрос ревью) |
| `targetSdk` | 35 | 36 (требование Play с 31.08.2026) |
| «Рассказать друзьям» | ссылка на GitHub | ссылка на страницу в Play |

Версия (`versionCode`/`versionName`) общая; `versionCode` только растёт.

## Ключ подписи
`C:\MeowsTools\meows.keystore`, alias `meows`, пароль — `C:\MeowsTools\keypass.txt`. Копию хранить вне ПК.
Чтобы APK с GitHub и версия из Play обновляли друг друга, подпись приложения в Play должна быть этим же ключом:
при создании приложения → «Целостность приложения» → «Подпись приложения Play» → «Использовать существующий ключ» (экспорт PEPK-инструментом;
команду показывает сама консоль). Сделать это нужно до первой загрузки релиза.

## Политика конфиденциальности
Файл `docs/privacy/index.html`, публикуется через GitHub Pages (Settings → Pages → Branch `main`, папка `/docs`):
`https://mrme0ws.github.io/meows-vpn-app/privacy/`. Меняешь сбор данных — обнови политику и форму «Безопасность данных».

## Чек-лист консоли
1. Создать приложение: «Meows», русский, «Приложение», «Бесплатное».
2. Подпись приложения — существующий ключ (см. выше).
3. Политика приложения: URL политики; «Безопасность данных» (ниже); декларация VpnService; декларация foreground service `specialUse` (подтип `vpn`, видео: подключение/отключение и уведомление); `QUERY_ALL_PACKAGES` (раздельное туннелирование: выбор приложений, исключаемых из VPN); рейтинг контента; аудитория 18+; реклама — нет; доступ к приложению — дать ревьюеру рабочую ссылку подписки.
4. Карточка (тексты — `docs/play-listing.md`).
5. Закрытое тестирование: личный аккаунт — **12 тестировщиков, непрерывно 14 дней**, затем «Запросить доступ к продакшену».
6. Продакшен-релиз: загрузить `MeowsVPN-play.aab`, описание «что нового», отправить на проверку.

## Безопасность данных (шпаргалка)
- Данные не продаются и не передаются третьим лицам (отправка VPN-сервису, который выбрал сам пользователь, — по запросу пользователя).
- Передаются: **идентификаторы устройства** (HWID, случайный; можно выключить) и **информация об устройстве** (модель, версия ОС) — для функциональности (учёт устройств тарифа); шифруются при передаче (HTTPS); удаление — через поддержку сервиса.
- Содержимое трафика, история, местоположение, контакты — не собираются.

## Проверено / не проверено
Собраны оба варианта: `play` (AAB) и `direct` (APK). В манифесте `play` нет `REQUEST_INSTALL_PACKAGES` и FileProvider, `targetSdk 36`.
Play-вариант установлен на Pixel 10 через `bundletool` (2026-11-18): запускается, VPN поднимается (`tun0`), служба работает с `targetSdk 36`, статистика идёт. Не проверено: другие ABI/устройства, длительная работа, установка именно из Play (подпись/раздача сплитов делает Google).

Графика для карточки лежит в `docs/play-assets/` (иконка 512, баннер 1024×500, 4 скриншота с Pixel 10).
