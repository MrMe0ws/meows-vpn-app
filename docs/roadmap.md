## Идеи
- Иллюстрации кота для разных состояний (подключается, ошибка) вместо одного логотипа.
- Предиктивные анимации перехода главная ⇄ настройки, shared element для кота.
- Виджет подключения (Glance), Quick Tile уже есть.
- Адаптивная раскладка для планшетов (список серверов рядом с котом).
- Статистика трафика сессии, график скорости.
- Локализация (en) — тексты вынести в `strings.xml`.

## Windows (идея, одобрено владельцем: «в рамках этого проекта, отдельная подпапка»)
Папка `windows/` в этом репозитории. Compose Multiplatform Desktop (общий интерфейс), ядро Xray для Windows (`GOOS=windows`, без cgo). Режимы: «системный прокси» (без прав админа) и TUN (Wintun, нужны права админа). Установщик/портативный exe в GitHub Releases с тегом `windows-vX.Y.Z`; обновления тем же механизмом (`UpdateChecker`, ассет `.exe`/`.msi`). Сначала вынести логику подписки из `XKStore` (Android-зависимая) в общий модуль. Подпись кода платная — без неё SmartScreen предупреждает при первом запуске.
