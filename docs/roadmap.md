## Идеи
- Иллюстрации кота для разных состояний (подключается, ошибка) вместо одного логотипа.
- Предиктивные анимации перехода главная ⇄ настройки, shared element для кота.
- Виджет подключения (Glance), Quick Tile уже есть.
- Адаптивная раскладка для планшетов (список серверов рядом с котом).
- Статистика трафика сессии, график скорости.
- Локализация (en) — тексты вынести в `strings.xml`.
