# Meows для Windows

Папка `windows/` — Compose Multiplatform Desktop (Kotlin/JVM), тот же интерфейс Material 3, что и на Android (палитры, спящий кот и лапка, нижняя плавающая панель).

## Как устроено
```
Meows.exe (JVM + Compose)  ──stdin/stdout──►  meows-core.exe (Go, Xray-core)
   подписка, серверы, UI                        локальный SOCKS5 127.0.0.1:10808 + HTTP 127.0.0.1:10809
   системный прокси Windows  ◄── включает/возвращает ──┘
```
- **Ядро** — тот же Go-код (`core/`), собранный под Windows: `core/build-windows.ps1` → `windows/resources/windows-x64/meows-core.exe` (+ geo-файлы). Точка входа `core/desktop_main.go` (локальные прокси вместо TUN); маршрутизация (`routing.go`, `geo.go`, `conf.go`) общая с Android.
- **Закрылось приложение — закрылось ядро:** ядро читает stdin; закрытие stdin = выход.
- **Системный прокси:** `vpn/SystemProxy.kt` (реестр HKCU + WinInet через JNA). Прежние значения запоминаются; при аварийном выходе восстанавливаются при следующем запуске.
- **Подписка:** `data/Subscription.kt` — как на Android: User-Agent `MeowsVPN/<версия>` с откатом на Happ, `x-hwid` = хеш MachineGuid, `x-device-os: Windows`.
- **Пинг:** `vpn/PingRunner.kt` — режим `measure` ядра (реальный пинг через сервер).
- **Данные:** `%APPDATA%\Meows` (settings.json, core.json, geo/).

## Сборка
`cd windows; .\build.ps1` → `windows\dist\Meows-win-x64-<версия>.zip` (портативная папка: Meows.exe + JRE + ядро). Нужен JDK 17 из `C:\MeowsTools`. Установщик (MSI/EXE) требует WiX — пока не делаем.

## Что есть и чего нет (v1.0.0, первая версия)
Есть: добавление подписки (вставка/ввод, `meows://add/…` пока только вручную), список серверов, подключение/отключение через системный прокси, пинг, обновление подписки, темы и палитры, блок рекламы, расширенное «российские сайты напрямую», кабинет/поддержка.
Нет (по плану): режим TUN (Wintun, права администратора), автообновление приложения и гео-файлов, трей и автозапуск, `meows://` как протокол Windows, исключение приложений, установщик, подпись кода (без неё SmartScreen предупреждает), приложения без VPN (системный прокси их не касается: часть программ его игнорирует).

## Не проверено
Подключение с реальной подпиской: тест регистрирует ПК как новое устройство (лимит HWID в панели) — нужно согласие владельца. Запуск окна и ядро проверены.

## Тех. долг
Логика подписки продублирована с Android (`XKStore.java` ↔ `data/*.kt`); дальше — общий модуль Kotlin Multiplatform.
