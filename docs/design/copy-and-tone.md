# Тексты интерфейса

- Язык — русский. Название приложения — **«Мяус VPN»** (не «МЯУС VPN»).
- Тон: дружелюбный, короткий, без канцелярита; можно лёгкий «кошачий» акцент в пустых состояниях и на кнопке подключения («Кот спит…»), но не в ошибках и настройках.
- Кнопки — глаголы: «Добавить», «Обновить», «Скачать», «Установить». Без точки в конце. Не «ОК» — «Понятно».
- Заголовки — существительные, без точки: «Оформление», «Маршрутизация».
- Ошибки: **что случилось + что делать**. Не показываем сырые исключения без пояснения («Нет связи с сервером подписки. Проверьте интернет.»).
- Пояснения под группами настроек — одно-два предложения, объясняют последствия.
- Числа: десятичная запятая («184,7 МБ»), даты `дд.мм.гггг`, склонения через `pluralRu`.
- Термины: «подписка», «сервер», «пинг», «ядро» (не «core»), «кабинет» (личный кабинет).
