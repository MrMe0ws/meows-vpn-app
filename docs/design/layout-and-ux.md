# Раскладка, компоненты, пользовательский путь

## Структура приложения
- **Главная** — всё главное на одном экране: кнопка-кот → подписка → список серверов. Пользователь не ходит по вкладкам.
- **Настройки** — отдельный экран (шестерёнка). Главная настроек — **короткий список свёрнутых разделов** (иконка, название, текущее значение);
  детали — на странице раздела. Глубина: Настройки → Раздел → (подраздел). Больше трёх уровней не делаем.
- Нижней навигации нет: два «места» (главная/настройки) не оправдывают `NavigationBar`. Появятся 3+ равноправных раздела — вернём.

## Главная: порядок сверху вниз
1. Верх — только название «Мяус VPN» (без кнопок: до верха экрана палец не тянется).
2. Кот-кнопка (200dp) и статус/таймер. Главное действие экрана — одно. Отключено — спящий кот; подключаемся/подключено — **лапка в цвете темы** (`primary`) внутри кольца.
3. «Скрыть все / Показать все».
4. Шапка подписки (название, меню; трафик, срок, объявление, кнопки «Кабинет/Продлить» и «Поддержка») + список серверов единым скруглённым блоком.
5. **Нижняя плавающая панель** (`HorizontalFloatingToolbar`, Material 3 Expressive) — все действия в зоне большого пальца:
   Настройки · Добавить подписку (меню: буфер / QR / вручную) · Пинг всех · Обновить подписку. Пинг и «Обновить» — только если есть подписка.
   Панель прячется при прокрутке вниз и плавно возвращается при прокрутке вверх.
   Цвет панели — `vibrant` (контейнер `primaryContainer`): стандартный `surfaceContainer` сливался со списком (проверено на устройстве).
   Правило: частые действия экрана — в нижней панели; верхний край экрана остаётся пустым от кнопок.
## Жесты и действия
| Действие | Как |
|---|---|
| Подключить / отключить | тап по коту (haptic) |
| Выбрать сервер | тап по строке |
| Пинг одного сервера | **свайп справа налево** открывает под строкой кнопку «Пинг» (значок + подпись, как в Telegram); пинг — нажатием на кнопку; тап по строке закрывает |
| Конфиг сервера | долгое нажатие по строке |
| Добавить подписку | «+» в нижней панели → вставить из буфера / QR / вручную |
| Назад | системный жест (предиктивный) |

Каждое скрытое действие (свайп, долгое нажатие) дублируется подсказкой под списком и, где возможно, видимой кнопкой.

## Компоненты — что чем
- Группа настроек: `Card` (`surfaceContainer`, `extraLarge`) с `ListItem` внутри; заголовок группы — `labelLarge` в `primary`; пояснение под группой — `bodySmall`.
- Выбор одного из 2–3: `SegmentedButton`. Из многих: диалог с `RadioButton`. Включить/выключить: `Switch` в `ListItem` (вся строка кликабельна).
- Подтверждение/ввод: `AlertDialog` (коротко) или `ModalBottomSheet` (ввод). Фоновая загрузка: `LoadingIndicator`/wavy-индикатор.
- Список со свайпом и выбором — единый блок со скруглением только сверху и снизу.

## Отступы и размеры
- Боковые поля 16dp (карточки в списке — 12dp), вертикальный ритм кратен 4dp (8/12/16/24).
- Цели нажатия ≥ 48dp. Иконки 24dp (в кружках настроек 20dp).
- Системные отступы — `WindowInsets`; не хардкодим высоту статус-/навигационной панели.

## Состояния — обязательно продумать
Пусто (нет подписки — `EmptyCard` с одним главным действием), загрузка, ошибка (понятный текст + что делать), успех (снэкбар),
отключено / подключаемся / подключено, нет сети. Для новой фичи в PR/отчёте перечисли, как выглядят все состояния.

## Пользовательский путь (первый запуск)
Открыл приложение → видит спящего кота и «Добавьте подписку» → вставил ссылку (или `meows://add/…` из кабинета, или QR) →
серверы появились → тап по коту → системный диалог VPN (один раз) → «Подключено».
Любое лишнее действие на этом пути — повод упростить.
