# Интеграция с магазином Мяус VPN

Всё работает **без изменений в боте и панели** — данные берутся из заголовков подписки и констант (`shop/ShopLinks.kt`).

| Что | Где в приложении | Источник |
|---|---|---|
| Кабинет | кнопка под подпиской, меню подписки | заголовок `profile-web-page-url` (запасной — `cabinet.me0ws.store`) |
| Продлить | вместо «Кабинет», когда осталось ≤ 7 дней или подписка закончилась | срок из `subscription-userinfo`, ссылка — кабинет |
| Поддержка | кнопка под подпиской → `ui/home/SupportSheet.kt` | заголовок `support-url` (запасной — `t.me/VPNmeows_bot`) |
| Отчёт для поддержки | в листе «Поддержка», копируется в буфер | `shop/Diagnostics.kt`: версия, устройство, сервер, срок, VPN, HWID (8 символов), последняя ошибка. Ссылка подписки не включается |
| Лимит устройств | диалог ошибки с кнопкой «Открыть кабинет» | `MeowsViewModel.fetchError` по слову «лимит» в тексте ошибки `XKStore.fetch` |
| Поделиться | Настройки → «Рассказать друзьям» | ссылка на релизы GitHub |
| Объявление | текст в карточке подписки | заголовок `announce` |

## Идеи, требующие изменений на стороне бота/панели (позже)
- Статус серверов («Германия 3 недоступна») — нужен источник данных. Пока работает вручную: админ пишет текст в `announce` в Remnawave.
- Список устройств с кнопкой «Удалить» — нужен API кабинета.
- Реферальная ссылка в «Поделиться» — нужен эндпоинт кабинета.
