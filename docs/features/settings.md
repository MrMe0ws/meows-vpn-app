# Настройки

Главная настроек (`SettingsHome`) — свёрнутые разделы; каждый открывает свою страницу (`ui/settings/pages/*`). Роутер — `SettingsScreen.kt`, enum `SettingsPage` (с `parent` для «назад»).
Прокрутка каждой страницы хранится в роутере (`LocalPageScroll`, `SettingsComponents.kt`): при возврате с подстраницы список остаётся на месте, при заходе вперёд (`go`) начинается сверху. На Windows состояние прокрутки создаётся в `SettingsScreen` до раннего `return` в «Автопереключение». Проверено только сборкой, на устройстве не смотрел.

| Раздел | Файл | Содержимое |
|---|---|---|
| Оформление | `AppearancePage` | тема, цвет (обои/палитры), AMOLED |
| Маршрутизация | `RoutingPage` → `AppsPage` | «Весь трафик через VPN», российские приложения напрямую, приложения без VPN (подробно: `geo-and-routing.md`) |
| Для опытных | `AdvancedPage` → `RoutingProfilesPage`, `BypassPage` | профили маршрутизации, категории/сайты мимо VPN, «все российские сайты напрямую», локальная сеть мимо VPN, защита от обрыва (Always-on) |
| Подписка | `SubscriptionPage` | автообновление, обновление при запуске, напоминания (HWID отправляется всегда, настройки нет) |
| Подключение | `ConnectionPage` | автозапуск, автопереключение (строка с тумблером → страница `AutoSwitchPage`: на какие серверы переключаться), обход в мобильной сети (строка с тумблером → `MobileBypassPage`, см. `mobile-bypass.md`) |
| Пинг | `PingPage` | способ, адрес, таймаут, время показа, пинг при запуске |
| Обновления приложения | `UpdatesPage` | галочка «искать обновления», проверка, скачать/установить |
| О приложении | `AboutPage` | версия, HWID, поддержка, кабинет; внизу «Для разработчиков» → `UrlSchemesPage` |

Внизу главной настроек — ссылка на GitHub проекта.

## «Для опытных»
Сюда уходит всё, что меняет работу сети и требует знаний (маршруты, локальная сеть, Always-on); обычному пользователю трогать не нужно. На главной настроек это отдельная плитка в своей группе перед «Рассказать друзьям». На Windows — `AdvancedScreen` (профили и «все российские сайты напрямую»). Новая «умная» настройка — сюда, а не в «Маршрутизацию»/«Подключение». «Блокировать рекламу» убрана совсем: рекламу режет шаблон подписки (`category-ads`, `win-spy`), прежний флаг `blockAds` в ядро всегда уходит `false`. «Пинг» (с «Пинг при запуске») остаётся на главной.

## Правила
- Раздел растёт → дробим на подстраницы (как маршрутизация), а не удлиняем страницу.
- Значения хранятся в prefs `xk` (`XKStore.prefs()`); запись — `vm.setFlag/setPref`. Меняет VPN-маршруты → `reconnect = true`.
- Страницы со списками изменений (`BypassPage`, `AppsPage`) применяют результат при выходе (`DisposableEffect`), чтобы не переподключать VPN на каждый клик.
- Новая настройка: строка в нужной странице + краткое значение в `SettingsHome`, если оно полезно на виду.

## Иконка приложения (Android, «Оформление»)
Последняя строка страницы «Оформление» → страница «Иконка приложения» (`AppIconPage`/`AppIconPicker`): сверху предпросмотр, ниже сетка вариантов. Выбор запоминается сразу (`AppIcon.pending`), а применяется в `MainActivity.onStop` — когда приложение свёрнуто: смена компонента при открытом приложении выкидывает на рабочий стол. Варианты — `AppIcon.kt`: «Лайм» (по умолчанию, он же базовая иконка приложения `ic_launcher`), «Зелёная лапа» (вариант A), «Свечение» (B), «Классика» (прежняя бирюзовая), «Чёрная лапа», «Щит», «Глаза». Технически — семь `activity-alias` в манифесте (`.LauncherLime/Green/Glow/Classic/Paw/Shield/Eyes`; `AppIcon.ensureOne` включает «Лайм», если не включён ни один), включён ровно один (`setComponentEnabledSetting`, `DONT_KILL_APP`); LAUNCHER-фильтра у `MainActivity` нет. Ресурсы: `ic_launcher_fg_{glow,lime,classic,paw,shield,eyes}`, `ic_launcher_bg_lime`, цвета `ic_launcher_bg_{paw,shield,eyes}`, `mipmap-anydpi-v26/ic_launcher_*.xml`, превью `icon_prev_*`. Лаунчер может обновить ярлык с задержкой; закреплённый на рабочем столе ярлык при смене иконки может пропасть (поведение Android). Иконка в шапке уведомления — это иконка приложения из манифеста (лайм), система не даёт менять её по alias; маленькая иконка уведомления, плитка шторки и виджеты — белая лапка с когтями (`paw.png`, `ic_stat.png`, `ic_paw_on/off`). Файлы для гайдов и Google Play — `docs/brand/`.

## Группы на главной настроек
Пункты одного смысла лежат в одной группе (зазор между плитками 2 dp), разные по смыслу — в разных (зазор между группами 20 dp, `GROUP_GAP` в `SettingsComponents.kt`):
1. Оформление, Язык · 2. Подписка, Подключение, Маршрутизация · 3. Пинг, Статистика · 4. Обновления (не в Play), О приложении · 5. Для опытных · 6. Рассказать друзьям.
«Схемы URL-адресов» (`UrlSchemesPage`, открывается из «О приложении → Для разработчиков», на главной не показывается) — справка для разработчиков: какие ссылки понимает приложение (сейчас только `meows://add/{url}`; `happ://` приложение понимает для совместимости, но в справке не упоминается). Появится новая команда в `MainActivity.handleIntent` — добавить строку на страницу.

## Настройки, которые переподключают VPN
`vm.setFlag(key, value, reconnect = true)` → `reconnectIfNeeded(key)`: пока VPN перезапускается, строка с `SwitchRow(busy = vm.isApplying(key))` показывает «Применяем настройку…» и индикатор (тумблер заблокирован), в конце общий снэкбар «Настройка применена. VPN переподключился». Страховка — 30 с. Новая настройка с `reconnect = true` должна передавать `busy = vm.isApplying(ключ)` в свою строку. Если VPN выключен, ничего не показывается.
