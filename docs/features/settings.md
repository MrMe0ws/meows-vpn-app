# Настройки

Главная настроек (`SettingsHome`) — свёрнутые разделы; каждый открывает свою страницу (`ui/settings/pages/*`). Роутер — `SettingsScreen.kt`, enum `SettingsPage` (с `parent` для «назад»).

| Раздел | Файл | Содержимое |
|---|---|---|
| Оформление | `AppearancePage` | тема, цвет (обои/палитры), AMOLED |
| Маршрутизация | `RoutingPage` → `BypassPage`, `AppsPage` | российское напрямую, реклама, категории/сайты мимо VPN, приложения без VPN |
| Подписка | `SubscriptionPage` | автообновление, обновление при запуске, напоминания, HWID |
| Подключение | `ConnectionPage` | автозапуск, локальная сеть, Always-on/Kill switch (системные настройки) |
| Пинг | `PingPage` | способ, адрес, таймаут, время показа, пинг при запуске |
| Обновления приложения | `UpdatesPage` | галочка «искать обновления», проверка, скачать/установить |
| О приложении | `AboutPage` | версия, HWID, ссылка на GitHub |

Внизу главной настроек — ссылка на GitHub проекта.

## Правила
- Раздел растёт → дробим на подстраницы (как маршрутизация), а не удлиняем страницу.
- Значения хранятся в prefs `xk` (`XKStore.prefs()`); запись — `vm.setFlag/setPref`. Меняет VPN-маршруты → `reconnect = true`.
- Страницы со списками изменений (`BypassPage`, `AppsPage`) применяют результат при выходе (`DisposableEffect`), чтобы не переподключать VPN на каждый клик.
- Новая настройка: строка в нужной странице + краткое значение в `SettingsHome`, если оно полезно на виду.
