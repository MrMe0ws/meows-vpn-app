# Настройки

Главная настроек (`SettingsHome`) — свёрнутые разделы; каждый открывает свою страницу (`ui/settings/pages/*`). Роутер — `SettingsScreen.kt`, enum `SettingsPage` (с `parent` для «назад»).

| Раздел | Файл | Содержимое |
|---|---|---|
| Оформление | `AppearancePage` | тема, цвет (обои/палитры), AMOLED |
| Маршрутизация | `RoutingPage` → `BypassPage`, `AppsPage` | «Весь трафик через VPN», российские приложения напрямую, реклама, расширенное «все российские сайты», категории/сайты мимо VPN, приложения без VPN (подробно: `geo-and-routing.md`) |
| Подписка | `SubscriptionPage` | автообновление, обновление при запуске, напоминания, HWID |
| Подключение | `ConnectionPage` | автозапуск, автопереключение (строка с тумблером → страница `AutoSwitchPage`: на какие серверы переключаться), локальная сеть, Always-on/Kill switch (системные настройки) |
| Пинг | `PingPage` | способ, адрес, таймаут, время показа, пинг при запуске |
| Обновления приложения | `UpdatesPage` | галочка «искать обновления», проверка, скачать/установить |
| О приложении | `AboutPage` | версия, HWID, ссылка на GitHub |

Внизу главной настроек — ссылка на GitHub проекта.

## Правила
- Раздел растёт → дробим на подстраницы (как маршрутизация), а не удлиняем страницу.
- Значения хранятся в prefs `xk` (`XKStore.prefs()`); запись — `vm.setFlag/setPref`. Меняет VPN-маршруты → `reconnect = true`.
- Страницы со списками изменений (`BypassPage`, `AppsPage`) применяют результат при выходе (`DisposableEffect`), чтобы не переподключать VPN на каждый клик.
- Новая настройка: строка в нужной странице + краткое значение в `SettingsHome`, если оно полезно на виду.

## Иконка приложения (Android, «Оформление»)
Последняя строка страницы «Оформление» → страница «Иконка приложения» (`AppIconPage`/`AppIconPicker`): сверху предпросмотр, ниже сетка вариантов. Выбор запоминается сразу (`AppIcon.pending`), а применяется в `MainActivity.onStop` — когда приложение свёрнуто: смена компонента при открытом приложении выкидывает на рабочий стол. Варианты — `AppIcon.kt`: «Лайм» (по умолчанию, он же базовая иконка приложения `ic_launcher`), «Зелёная лапа» (вариант A), «Свечение» (B), «Классика» (прежняя бирюзовая). Технически — четыре `activity-alias` в манифесте (`.LauncherLime/Green/Glow/Classic`; `AppIcon.ensureOne` включает «Лайм», если не включён ни один), включён ровно один (`setComponentEnabledSetting`, `DONT_KILL_APP`); LAUNCHER-фильтра у `MainActivity` нет. Ресурсы: `ic_launcher_fg_{glow,lime,classic}`, `ic_launcher_bg_lime`, `mipmap-anydpi-v26/ic_launcher_*.xml`, превью `icon_prev_*`. Лаунчер может обновить ярлык с задержкой; закреплённый на рабочем столе ярлык при смене иконки может пропасть (поведение Android). Иконка в шапке уведомления — это иконка приложения из манифеста (лайм), система не даёт менять её по alias; маленькая иконка уведомления, плитка шторки и виджеты — белая лапка с когтями (`paw.png`, `ic_stat.png`, `ic_paw_on/off`). Файлы для гайдов и Google Play — `docs/brand/`.
