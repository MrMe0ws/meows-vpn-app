# Серверы и пинг

- Список серверов — `XKStore.servers()` (по конфигам подписки): `flag` (эмодзи-флаг из названия), `title`, `subtitle` («VLESS · TCP · Reality · JSON»), `endpoints`.
- Выбранный сервер — `XKStore.index()/setIndex()`; при смене во время подключения VPN переподключается (`reconnectIfNeeded`).
- Строка (`ui/home/ServerRow.kt`): тап — выбрать, **свайп справа налево открывает кнопку «Пинг» (как в Telegram), пинг — нажатием на неё**, долгое нажатие — JSON-конфиг.

## Пинг
- Режимы: **реальный** (ядро `measure` делает запрос через сервер) и **TCP** — настройка `P_PING_MODE`; адрес проверки `P_PING_URL`, таймаут `P_PING_TO`.
- API: `XKStore.pingAll`, `XKStore.pingSome(int[] only, …)`; результат в `XKStore.pings` (мс; −1 нет ответа; −2 UDP-протокол).
- VM: `ping()` (все), `pingOne(i)` (свайп; индикатор в строке — `pingingOne`). Показ результата скрывается через `P_PING_KEEP` секунд (0 — всегда).
- «Выбрать быстрейший» — меню шапки подписки, берёт минимальный положительный пинг.
- Приложение исключено из VPN, поэтому пинг честный и при включённом подключении.
