# Гео-файлы и маршрутизация

## Кто что решает
1. **Правила из подписки** (шаблон Xray JSON хоста в Remnawave: split РФ/заблокированное/реклама/торрент) — главный источник маршрутизации. Приложение берёт конфиг выбранного сервера целиком (`outbounds`, `routing`, `dns`, балансеры), подменяет только входящий трафик на TUN (`core/conf.go`).
2. **Правила приложения** (`core/routing.go: addRouting`) добавляются **выше** правил шаблона:
   DNS Яндекса напрямую → свои приложения/сайты/категории пользователя напрямую → блок рекламы (`category-ads`, `win-spy`, если включено) → расширенное «Все российские сайты напрямую» (если включено).
3. **Российские приложения** (список `RU_APPS` в `XKVpnService`) целиком исключаются из VPN (`addDisallowedApplication`), настройка `ruApps`, по умолчанию включена.

## Профили маршрутизации (Android и Windows)
Профиль — JSON формата Happ (`DirectSites/DirectIp`, `ProxySites/ProxyIp`, `BlockSites/BlockIp`, `GlobalProxy`, `RouteOrder`, `DomainStrategy`). Выбор: «Настройки → Маршрутизация → Для опытных → Профили маршрутизации» (`RoutingProfilesPage`, `routing/RoutingProfiles.kt`, pref `routeProfile`).
- **«Из подписки»** (по умолчанию) — профиль не передаётся, действуют правила шаблона подписки, как раньше. Имя берётся из `Name` заголовка `routing`, если есть.
- **Откуда правила «Из подписки».** Подписка отдаёт две разные вещи: **Xray-конфиг каждого сервера** (`routing.rules` — настоящий шаблон магазина) и **заголовок `routing`** (профиль Happ: имя, DNS, гео-ссылки, `DnsHosts`; списки у панели обычно пусты). При выборе «Из подписки» ядро использует Xray-правила как есть. Чтобы их можно было **посмотреть** («Посмотреть» в меню ⋮, только чтение) и **скопировать**, `XrayRules.kt` переводит правила выбранного сервера в списки профиля: цель freedom → «напрямую», blackhole → «блок», остальное/балансировщик → «через VPN»; правила без доменов/IP (порты, протоколы, DNS) не переносятся (торренты по протоколу `bittorrent` — тоже). Порядок групп — по последнему правилу каждой группы (так «через VPN» остаётся выше широкого «напрямую»). Правила у серверов подписки **различаются** (например, «Германия 2» добавляет криптобиржи напрямую, «Обход LTE» — короткий набор без «через VPN»): копия берётся с выбранного сервера.
- **Встроенные — «Мяус» и «RoscomVPN»**, оба редактируются (правка хранится отдельно, pref `routeBuiltin`; в меню ⋮ появляется «Сбросить к исходному», на карточке чип «Изменён»). «Мяус» — типовой шаблон магазина, снятый с реальной подписки (общий набор основных серверов: 12 списков напрямую, 32 домена через VPN, блок `win-spy`/`category-ads`, DNS как в шаблоне); при смене шаблона в панели профиль в коде надо обновить вручную (`RoutingProfiles.kt`). «RoscomVPN» — копия `HAPP/DEFAULT.JSON` из hydraponique/roscomvpn-routing (при обновлении upstream тоже вручную). Теги обоих есть во вшитых гео-файлах (`ru-blocked-all`, `category-ads-all` там нет — `sanitizeGeo` их бы отбросил).
- Ядро (`core/profile.go`, поле `profile` в опциях): профиль **заменяет** правила подписки; личные надстройки (`ruApps`, реклама, «Мимо VPN», VkusVill) остаются выше. Локальная сеть всегда напрямую. «Весь трафик через VPN» главнее профиля. Битый JSON профиля = правила подписки.
- **Свои профили** (`routing/CustomProfiles.kt`, `RouteProfile.kt`): `+` в «Профили» — создать, ⋮ — Изменить / Копировать / Удалить. «Копировать» есть у всех (у «Из подписки» — правила выбранного сервера, см. выше). Редактор — `ProfileEditPage.kt`: основное, списки напрямую / через VPN / блок (домены и IP), DNS, порядок правил, стратегия доменов. Правка выбранного профиля переподключает VPN. Профили хранятся в prefs слота подписки (`routeProfiles`).
- **DNS профиля:** `RemoteDNS*` (для трафика через VPN) и `DomesticDNS*` (для прямых доменов `DirectSites`) → `dns.servers`; пусто — DNS подписки. Типы: DoH, DoU (обычный UDP), TCP. **DoT нет:** ядро Xray его не поддерживает.
- **Поделиться / QR / импорт** (`ProfileDialogs.kt`): ссылка профиля — `happ://routing/add/<base64 JSON>` (совместима с Happ и INCY). «Поделиться» — системное меню, «QR» — код (zxing; очень большой профиль в QR не помещается — тогда только ссылкой). Импорт: значок вставки в топбаре «Профили» — вставить ссылку/base64/JSON или отсканировать QR; профиль добавляется как свой. «Поделиться»/«QR» нет у профиля «Из подписки».
- FakeDNS, Chunk-файлы и свои гео-URL профиля пока не поддерживаются (гео-ссылки берутся только из заголовка подписки). `DnsHosts` профиля идут в `dns.hosts`, в редакторе не показываются, но сохраняются.
- Смена профиля переподключает VPN. Не проверено на устройстве: что сайты ведут себя как с правилами подписки; проверены сборка и тесты ядра.

## Гео-файлы
Шаблоны используют теги roscomvpn (`whitelist`, `category-ru`, `torrent`, `geoip:direct` …). Приложение держит **те же файлы**, что Happ скачивает по ссылке из панели (вшиты в `assets/geosite.dat`, `assets/geoip.dat`; закреплены в панели: geosite `@202604152235`, geoip `@202605210659`).
- **Какие ссылки действуют** (`GeoUpdater`, Android `geo/GeoUpdater.kt`, Windows `geo/GeoUpdater.kt`): ссылки **выбранного профиля** (`Geoipurl`/`Geositeurl`, обе https) → ссылки из заголовка `routing` подписки (`happ://routing/add/<base64 JSON>`) → **вшитые** файлы. У встроенного RoscomVPN ссылки прописаны (`@202611201128`/`@202610120948`), у «Мяус» нет — он следует подписке.
- Файлы скачиваются в `files/geo/` (Windows — `%APPDATA%\Meows\geo`) с маркером `custom`; битый/пустой/гигантский файл не заменяет рабочий. Без маркера `XKVpnService`/`CoreProcess` держат там вшитые; если ссылок нет ни у профиля, ни у подписки, маркер снимается и возвращаются вшитые. Файлы **общие на приложение**, поэтому профиль со своими ссылками меняет их при выборе (ссылки закреплены по версии — скачивание только при смене ссылок, лишнего трафика нет).
- **Когда обновляются:** после обновления подписки, при выборе/сохранении/сбросе профиля (сначала файлы, потом переподключение VPN — иначе правила с новыми тегами пропали бы), и кнопкой «Обновить» в блоке «Гео-данные» редактора профиля (принудительно; кнопка активна только у выбранного профиля). Применяются при подключении VPN.
- В редакторе профиля — свёрнутый блок «Гео-данные»: GeoIP URL, GeoSite URL, статус («Гео-данные загружены» / «Используются файлы из приложения»), дата и «Обновить». Пустые ссылки — из подписки, иначе вшитые.
- На Windows загрузчика гео раньше не было (использовались только вшитые) — теперь есть, и ссылки панели тоже подхватываются.
- Теги, которых нет в файлах, ядро **молча отбрасывает** (`core/geo.go: sanitizeGeo`) — правило без тегов пропадает. Новый тег в шаблоне = сверить с бинарником (`docs/` магазина: `geosite.md`).

## Режим «Весь трафик через VPN» (`allVpn`, по умолчанию выключен)
Для поездок: российский сайт из-за границы с обычным split не открыть (трафик идёт напрямую, с местным IP). Включённый режим (`core/allvpn.go: applyAllVpn`) **отбрасывает правила подписки и личные исключения** и оставляет: торренты напрямую (`protocol: bittorrent`, `geosite:torrent`), локальная сеть напрямую (`geoip:private`), блок рекламы (если включён), дальше «всё → VPN». Не действуют: российские приложения напрямую (`ruApps`, Android), «Мимо VPN» (категории, сайты, приложения), «Все российские сайты напрямую», обход ВкусВилл. Переключатель: Android — «Маршрутизация» (первая строка), Windows — «Настройки → Маршрутизация» и в выпадающем списке режима на главной (под «Все программы» / «Системный прокси»). Меняется при подключённом VPN → переподключение. В настройках неактивные в этом режиме переключатели («Российские приложения напрямую», «Все российские сайты напрямую») показываются серыми с пометкой «не действует», значения не сбрасываются — после выключения режима выбор возвращается.
Не проверено на устройстве: что сайты РФ реально открываются из-за границы (тест ядра проверяет только состав правил и загрузку конфига).

## Настройки (Маршрутизация)
- «Российские приложения напрямую» — `ruApps`, по умолчанию включено.
- «Блокировать рекламу» — `blockAds`.
- «Все российские сайты напрямую» — `ruDirect`, **по умолчанию выключено** (`.ru`, `.su`, `.рф` + списки поверх подписки): в шаблонах Default и Crypto RU `domain:ru` намеренно нет.
- Мимо VPN: категории (`ru`, `apple`, `microsoft`, `games` — теги roscomvpn), свои сайты, свои приложения.

## Не проверено
Как именно ведёт себя маршрутизация на реальных сайтах после смены гео-файлов и дефолтов (проверено: ядро стартует, VPN поднимается, подписка грузится).
