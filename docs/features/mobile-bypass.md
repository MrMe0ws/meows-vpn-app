# Обход в мобильной сети (Android; с 1.9.0 в GitHub-APK, в Play-сборке тоже есть, но AAB 1.9.0 не загружался)

Настройка «Подключение → Обход в мобильной сети». Выключена по умолчанию, включает пользователь.
Когда телефон переходит с Wi-Fi на мобильный интернет, Meows подключается к серверу обхода (белые списки), на Wi-Fi возвращается прежний сервер.

## Какие серверы считаются серверами обхода
- По названию: `обход`, `белые списки` / `белый список` без учёта регистра (`MobileBypass.isAuto`).
- Пользователь может отметить любые серверы вручную (страница `MobileBypassPage`), серверы показаны по подпискам. Пока ручной выбор не делали, действует поиск по названию; после первого нажатия список фиксируется (prefs `mobBypassSel`, ключи `слот|название`).
- Серверы берутся из **всех** подписок. Подписка — отдельный слот (`XKStore`), VPN подключается к активной, поэтому переключение на сервер из другой подписки = `XKStore.activate(слот)` + `setIndex`.
- Отмечено несколько — берётся первый из списка, который отвечает на пинг (серверы с UDP-протоколом, которые проверить нельзя, — только если никто не ответил).
- Нет ни найденных, ни отмеченных серверов — тумблер неактивен, подпись «Недоступно на вашем тарифе»; строка ведёт на страницу, где можно отметить серверы вручную.

## Как работает
- `MobileBypass` (логика, prefs `mobBypass`, `mobBypassPrev`) + `MobileBypassWatcher` (сетевой колбэк, пока VPN подключён).
- Сеть определяется по `ConnectivityManager.allNetworks` без VPN: приоритет у «проверенных» сетей, Wi-Fi выше мобильной. Мобильная сеть без «проверенного» доступа тоже считается мобильной: при белых списках проверка Android не проходит.
- Перед запуском туннеля (`XKVpnService.startVpn`) вызывается `MobileBypass.evaluate`: если уже мобильная сеть — сразу сервер обхода, без лишнего переподключения.
- Смена сети учитывается через 4 с, переключения не чаще раза в 30 с. Ни один сервер обхода не ответил — ещё 3 попытки через 20 с.
- Прежний сервер хранится на диске (`слот|название`), возврат — при переходе на Wi-Fi. Ручной выбор сервера пользователем (`MeowsViewModel.select`) стирает «прежний» и пока сеть не сменилась не даёт обходу вмешиваться.
- Выключили тумблер во время обхода — возвращается прежний сервер.
- Нет сети совсем — ничего не делаем, ждём.
- Не трогаем: VPN сам не включается; роуминг не учитывается; Ethernet считается как Wi-Fi.

## Не проверено на устройстве
Реальное поведение на смене Wi-Fi ↔ LTE, длительность переподключения, реакция прошивок. Проверять на Pixel 10: Wi-Fi → мобильная, обратно, выключение Wi-Fi при включённом VPN, режим «в самолёте», ручная смена сервера во время обхода, перезапуск приложения.
