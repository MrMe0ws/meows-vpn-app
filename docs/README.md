# Документация Мяус VPN

Точка входа для агентов — `../AGENTS.md`. Здесь — подробности.

```
docs/
  architecture/   как устроено
    overview.md     слои и потоки данных
    structure.md    карта папок и файлов (обновлять при добавлении файлов!)
    vpn-core.md     ядро Xray, VpnService, Java-слой XK*
  conventions/    как пишем
    files-and-code.md   размер файлов, папки, имена, комментарии
  design/         как выглядит и ощущается (Material You)
    material-you.md     принципы и что можно / нельзя
    color-and-theme.md  цветовые роли, динамические цвета, палитры, темы
    layout-and-ux.md    раскладка, компоненты, навигация, жесты, пользовательский путь
    copy-and-tone.md    тексты интерфейса
  features/       как работает каждая фича
  build.md        сборка и подпись
  release.md      выпуск релиза на GitHub (для автообновления)
  roadmap.md      что дальше
  decisions.md    журнал решений
```

Правило: один файл — одна тема, до ~100 строк. Выросло — режем на два и обновляем эту карту.
