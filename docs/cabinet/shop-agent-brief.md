# Задача для агента проекта `remnawave-telegram-shop`: добавить приложение Meows в гайд подключения

Этот файл — самодостаточное задание. Читай целиком, потом делай. Проект магазина — **этот** репозиторий (`remnawave-telegram-shop`); приложение Meows живёт в другом репозитории (`MrMe0ws/meows-vpn-app`) и здесь **не меняется**.

## Зачем это делаем
У сервиса «Мяус VPN» появилось собственное приложение **Meows** (Android уже выпущено, Windows — в доработке, iOS — в планах). Сейчас в кабинете («Установка»/«Подключение») предлагаются только сторонние: INCY, Happ, FlClashX. Нужно предложить своё приложение как вариант подключения, чтобы:
- пользователь ставил приложение сервиса, которое понимает правила маршрутизации подписки (российские сайты напрямую, остальное через VPN), лимит устройств по HWID и показывает трафик/срок/объявления из заголовков подписки;
- кнопка «Подключить» в кабинете добавляла подписку в Meows в один тап (deep link `meows://add/…`).

Порядок в гайде (решение владельца): **на Windows — 1 место, на Android — 2 место**. На остальных платформах (iOS, macOS, Linux, TV) Meows не добавлять: приложения для них нет.

## Что за приложение — факты, которые нужны для текстов и ссылок
- Название в интерфейсе: **Meows** (латиницей, без «VPN»). «Мяус VPN» — название сервиса.
- Android: от Android 7.0, APK (в Google Play **нет**), ставится вручную из GitHub Releases; Play Protect может попросить подтвердить установку — об этом надо предупредить в шаге установки. Релизы — теги `android-vX.Y.Z`. Сейчас выпущена **1.4.0**.
- Windows: Windows 10/11 x64, установщик `.msi` (ставится на пользователя, без прав администратора). Релизы — теги `windows-vX.Y.Z`. Выпущен 1.0.0 (файл `Meows-1.0.0.msi`).
  - Подписи кода нет: при первом запуске установщика SmartScreen может предупредить («Подробнее → Выполнить в любом случае»). Упомяни в тексте.
  - Режим «Все программы» (TUN, по умолчанию) просит права администратора при запуске приложения (окно UAC) — это нормально, надо сказать «нажмите Да».
- **Прямые постоянные ссылки на свежую сборку** (без номера версии; всегда указывают на последний релиз, обновляются автоматически):
  - Android: `https://github.com/MrMe0ws/meows-vpn-app/releases/download/android-latest/Meows.apk`
  - Windows: `https://github.com/MrMe0ws/meows-vpn-app/releases/download/windows-latest/Meows.msi`
  Используй их в кнопках «Скачать» (кнопка сразу качает файл). Страница релизов — `https://github.com/MrMe0ws/meows-vpn-app/releases` — запасная ссылка «все версии». Ссылку вида `/releases/latest/download/<файл>` использовать **нельзя**: «latest» — самый свежий релиз репозитория вообще (Android или Windows), а имена файлов в обычных релизах содержат версию.
- Deep link: `meows://add/<ссылка подписки>` — ссылка **без кодирования и без base64** (как у `happ://add/` и `incy://add/`). Приложение принимает и URL-кодированную, и сырую. Шифрования deep link у Meows **нет**.
- Android + Chrome: ссылку на пользовательскую схему Chrome часто не открывает. Надёжнее `intent://add/<ссылка>#Intent;scheme=meows;package=app.meows.vpn;S.browser_fallback_url=<url-encoded страница релизов>;end` — при отсутствии приложения откроется страница загрузки. Готовый пример страницы: `docs/cabinet/open-in-app.html` в репозитории приложения. Посмотри, как кабинет уже решает это для других приложений (комментарий в `useConnectionGuide.ts` про обход Telegram WebView), и сделай так же; отдельную страницу заводить не надо, если существующий механизм справляется.
- Иконка приложения: бирюзовая лапка на тёмном круге. Файл в репозитории приложения: `windows/src/main/resources/icon.png` (квадрат с кругом). Попроси у владельца файл или скачай из `https://raw.githubusercontent.com/MrMe0ws/meows-vpn-app/main/windows/src/main/resources/icon.png`.

## Что нужно изменить (проверь пути — они из рабочей копии на 2026-11-17)

### 1. `translations/cabinet/app-config.json`
Структура: `platforms.<windows|android>` — массив приложений. Добавь объект:
- в `platforms.windows` — **первым** элементом (индекс 0);
- в `platforms.android` — **вторым** (после INCY, перед Happ).

Поля повторяют существующие записи (смотри INCY): `id`, `name`, `isFeatured`, `urlScheme`, `installationStep`, `addSubscriptionStep`, `connectAndUseStep`, при желании `additionalAfterAddSubscriptionStep`.
- `id`: `"meows"`, `name`: `"Meows"`, `urlScheme`: `"meows://add/"`.
- `isFeatured`: **не меняй** существующие значения (рекомендуемым остаётся INCY). Предложи владельцу в отчёте сделать Meows рекомендуемым на Windows после выхода Windows-релиза — решает он.
- Тексты на русском (`"ru"`), тон — как у соседних записей. Предлагаемые тексты:

Android:
- installationStep.description: «Скачайте приложение Meows из GitHub и установите его. Android может предупредить об установке из неизвестного источника — разрешите её для браузера или файлового менеджера. Если Play Защита просит проверить приложение — нажмите «Всё равно установить».»
- installationStep.buttons: одна кнопка «Скачать с GitHub» → `https://github.com/MrMe0ws/meows-vpn-app/releases/download/android-latest/Meows.apk` (прямая загрузка).
- addSubscriptionStep.description: «Нажмите кнопку ниже — Meows откроется и добавит подписку сам. Если нет — скопируйте ссылку подписки, в Meows нажмите «+» → «Вставить из буфера обмена».»
- connectAndUseStep.description: «Нажмите большую кнопку с котом — он проснётся, и VPN включится. Согласитесь на создание VPN-подключения, когда Android спросит. Российские сайты открываются напрямую, остальное идёт через VPN.»

Windows:
- installationStep.description: «Скачайте установщик Meows (файл .msi из последнего релиза Windows) и запустите. Права администратора для установки не нужны. Windows может показать предупреждение SmartScreen — нажмите «Подробнее» → «Выполнить в любом случае».»
- installationStep.buttons: «Скачать с GitHub» → `https://github.com/MrMe0ws/meows-vpn-app/releases/download/windows-latest/Meows.msi` (прямая загрузка).
- addSubscriptionStep.description: «Нажмите кнопку ниже — Meows откроется и добавит подписку сам. Если нет — скопируйте ссылку подписки, в Meows нажмите «Добавить» слева и вставьте её.»
- connectAndUseStep.description: «При запуске Meows попросит права администратора — нажмите «Да»: это нужно, чтобы весь интернет компьютера шёл через VPN. Нажмите большую кнопку справа — когда появится «Подключено», всё работает.»

Кнопка «Что нового / видео» (`additionalAfterAddSubscriptionStep`) — не добавляй, видео-инструкции для Meows нет.

⚠️ В `documentation/cabinet/connections-page.md` («Открытые вопросы») сказано, что `app-config.json` в репозитории — версия от 1 августа, а **боевой файл на проде может отличаться**. Правь файл в репозитории, а в отчёте напиши владельцу: «эти же два объекта нужно добавить в боевой `app-config.json`» (или попроси прод-версию и внеси в неё).

### 2. Иконка в кабинете — `web/cabinet/src/features/connections/guide/glyphs.tsx`
Иконки рисуются в функции `appGlyph()` по ключу (`key.includes('happ')`, `'incy'`, `'flclashx'`…); плитка — `AppTile` (тёмная `bg-slate-900` по умолчанию, белая для INCY).
- Добавь ветку `key.includes('meows')` с SVG лапки (бирюзовая `#00C8C8` на тёмном — плитка по умолчанию тёмная, подходит). Нарисуй упрощённую лапку: одна большая подушечка и четыре пальца (эллипсы) в `viewBox="0 0 50 50"`, `fill` бирюзовый. Иконку-картинку встраивать не нужно, если SVG выглядит достаточно узнаваемо; если у владельца есть готовый SVG — используй его.
- Если ключ неизвестен, кабинет рисует инициалы — убедись, что для Meows этого не происходит.
- Если иконки приложений есть ещё где-то (поиск по `incy` в `web/cabinet/src`: `useConnectionGuide.ts`, `i18n`, админка настроек `adminSettingsGroups.ts`) — посмотри, нужно ли там что-то для Meows (скорее всего нет).

### 3. Deep link — `web/cabinet/src/features/connections/useConnectionGuide.ts`
В функции `subscriptionPayloadForScheme` есть список `rawUrlPrefixes` (`happ://add/`, `incy://add/`, …) — приложения, которым ссылка подписки подставляется **как есть**. Добавь `'meows://add/'`. Иначе ссылка будет `encodeURIComponent`-кодирована (приложение это переживёт, но единообразие и совместимость с `intent://` лучше сырой).
- `encryptKeyForApp()` для `meows://` должен возвращать `''` — шифрования нет; так и есть, менять не надо. Проверь только режим «шифрование deep link включено» (описан в `documentation/cabinet/connections-page.md`): Meows должен вести себя как RabbitHole/FlClashX — подключаться по обычной ссылке и **не пропадать** из списка.

### 4. Документация и сборка (по правилам репозитория)
- Обнови `documentation/cabinet/connections-page.md` (раздел про приложения/порядок) и `CHANGELOG.md` — как делали предыдущие правки кабинета.
- В репозитории коммитится собранный `dist` кабинета (см. историю: «build(cabinet): пересборка dist»). Пересобери так же, как раньше, отдельным коммитом.
- Проверь визуально через `tools/cabinet-visual-check` (там фикстуры `connections.json`): Windows-список — Meows первый; Android — Meows второй; плитка с лапкой не «пустая»; кнопка ведёт на правильную ссылку.
- Не пушь и не деплой — вернёшь результат владельцу.

## Что нельзя делать
- Windows-релиз **уже выпущен** (`windows-v1.0.0`, 2026-11-17), Android — `android-v1.3.0`: добавляй обе платформы сразу. Ссылки — постоянные `android-latest` / `windows-latest` (см. выше), не `/latest/download/…`.
- Не меняй `isFeatured`, порядок остальных приложений и тексты существующих записей.
- Не пиши в разметке кабинета «Мяус»/«Meows» как бренд сервиса: кабинет нейтрален по бренду (`brand_name` из `/auth/bootstrap`), название приложения «Meows» — только в `app-config` как имя приложения.
- Не меняй бэкенд (Go), если не обнаружишь, что без этого нельзя; в `internal/cabinet/deeplink` лежат шифрованные ссылки только для Happ/INCY — Meows они не касаются.

## Как проверить, что готово
1. Кабинет → «Установка» → устройство «Windows»: первым в списке приложений **Meows** с иконкой-лапкой ; устройство «Android»: Meows вторым.
2. Выбираешь Meows → шаг 1 с кнопкой «Скачать с GitHub» ведёт на страницу релизов; шаг 2 «Добавить подписку» формирует `meows://add/https://…` (сырая ссылка, без кодирования); на Android в Chrome работает `intent://`-вариант.
3. Режим «шифрование deep link» включён → Meows остаётся в списке.
4. Другие приложения и платформы выглядят как раньше (сравни фикстурами).
