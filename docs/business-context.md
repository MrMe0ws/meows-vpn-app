# Контекст: магазин Мяус VPN

Приложение делается **для клиентов магазина Мяус VPN** — собственного VPN-сервиса владельца проекта. Цель — чтобы и пользователям, и админу было удобнее: фирменный клиент вместо сторонних (Happ, INCY), кабинет и поддержка в одно касание, обновления без магазина приложений, диагностика для поддержки.

## Как приложение связано с магазином

| Часть магазина | Публичный адрес | Связь с приложением |
|---|---|---|
| Лендинг | `me0ws.store` | ссылка на скачивание APK (GitHub Releases) |
| Личный кабинет (оплата, тарифы, устройства) | `cabinet.me0ws.store` | кнопки «Кабинет» и «Продлить»; ссылка `meows://add/…` с кнопки в кабинете добавляет подписку в приложение |
| Telegram-бот-магазин | `@VPNmeows_bot` | кнопка «Поддержка» (с отчётом-диагностикой) |
| Подписка | `sub.me0ws.store` | источник серверов: Xray JSON по ссылке подписки |
| Панель Remnawave | (закрыта) | выдаёт подписку и заголовки (`announce`, `support-url`, `profile-web-page-url`, `subscription-userinfo`, `profile-update-interval`) |

## Подписка и заголовки
- Приложение запрашивает подписку с `User-Agent: Meows/<версия>` и `x-hwid` — на стороне панели это правило «Meows App» (`^Meows`, см. `features/shop-integration.md`); оно отдаёт Xray JSON с шаблоном хоста и split-маршрутизацией. Запасной запрос как `Happ/3.9.0` ничего не даёт: такой UA получает заглушку-ссылки (проверено curl).
- Лимит устройств считается по HWID. Если он исчерпан, подписка не отдаётся — приложение предлагает открыть кабинет.
- `announce` в панели показывается в карточке подписки: так админ без изменений приложения может сообщить, например, что сервер временно недоступен.
- Тарифы: базовые (Trial/Default) — без «Обхода LTE», Premium/Ultra — с обходом. Приложение показывает серверы, которые пришли в подписке.

## Маршрутизация (как у клиентов магазина)
РФ и whitelist — напрямую, заблокированное — через VPN, реклама — блок, торрент — напрямую. В приложении это переключатели «Российское напрямую», «Блокировать рекламу», категории/сайты/приложения мимо VPN (`docs/features/settings.md`).

## Что требует изменений на стороне магазина (бот/панель)
См. `docs/features/shop-integration.md`: статус серверов, список устройств с удалением, реферальная ссылка, отдельное правило ответов панели для `^Meows`.

Инфраструктура (ноды, IP, доступы, шаблоны Remnawave) в этот репозиторий **не** входит и не публикуется.
